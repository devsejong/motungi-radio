# 모퉁이 라디오 웹 미리보기

데스크톱의 단일 재생기·취소 처리를 공유하는 별도 웹 진입점이다. 데스크톱 설치파일과 홈페이지 배포에는 포함하지 않았다.

## 실행

```sh
npm ci
npx vite --config web/vite.config.ts
```

http://127.0.0.1:1422/ 에서 확인한다. 정적 빌드는 `npx vite build --config web/vite.config.ts`이며 결과는 `dist-web/`이다.

## 현재 범위

- KBS·SBS·CBS·cpbc·BBS·FEBC·WBS·TBN 경인 공식 스트림 직접 연결
- 재생/정지, 이전/다음, 음량, 채널 서랍, 밝은/어두운 화면
- 마지막 채널·음량·테마만 localStorage에 저장. 새로 열 때 무음 시작
- 방송사 요청에는 방문자 IP 등이 전달된다. 별도 통계 SDK·운영 서버·우회 프록시는 없다.
- MBC·EBS는 브라우저 연결 미지원으로 공식 홈페이지에 안내한다. 브라우저의 CORS·지역 제한을 우회하지 않는다.
- KBS·SBS·cpbc 현재 프로그램 제목·썸네일을 공식 API에서 조회한다. 나머지는 자체 채널 워드마크(공식 CI가 아님)를 표시한다. 편성표, 채널 정렬·넘기기 제외, 설치형 PWA는 아직 구현하지 않았다.

## 검증 — 2026-11-01

TypeScript 검사, 스트림 경계 테스트 4개, 정적 빌드 통과. Chromium에서 KBS 1Radio·SBS 파워FM·CBS 음악FM·cpbc·BBS·FEBC·WBS·TBN 경인의 `playing` 이벤트를 실제 연결로 확인하고 정지했다. 음량 0 상태의 재생 이벤트이며 사람의 청취 검증이 아니다. 16개 지원 채널 전체를 개별 시험한 것은 아니다.

320/390px 가로 넘침 없음, 밝은/어두운 화면, 새로고침 후 마지막 채널·음량·테마와 무음 시작, 키보드 채널 펼침/닫힘, 미지원 채널 재생 비활성·공식 링크를 확인했다.

Safari·iPhone·Android 실기기, 모바일 백그라운드 재생, 공개 HTTPS 배포 환경은 미검증이다. 공개 전 웹 용도의 방송사 이용 조건과 개인정보 안내, 전체 채널 연결을 재확인한다.

프로그램 정보는 30초마다 갱신하며 종료 시각이 지나면 폐기한다. 조회·이미지 실패는 채널 커버로 대체하며 재생기를 호출하지 않는다. KBS는 채널·지역·날짜·시간 구간을 모두 대조하고 SBS는 동일 프로그램의 정사각 이미지를 우선한다. 웹 프리뷰에서 KBS 5개·SBS 2개·cpbc 이미지 로딩 확인. KBS 한민족은 정확히 일치하는 현재 행이 없어 커버를 유지했다.

썸네일 변경 후 프런트 79개·Rust 57개 통과(외부 연결 5개 제외), TypeScript·데스크톱/웹 빌드 통과. 이미지 실패·이전 이미지의 늦은 로딩·채널 불일치·종료 경계·자정 구간 회귀 검사 포함. KBS 공식 스트림 API가 반환하는 HappyFM/CoolFM의 -ad CDN 호스트를 정확한 허용 목록에 추가했고 HappyFM 재생 이벤트·정지 확인(음량 0).

## 데스크톱 UI — 2026-11-01

840px 이상에서는 왼쪽 고정 플레이어와 오른쪽 1열 채널 목록를 표시한다. 채널명·방송사·현재 프로그램으로 검색하고, 선택과 실제 재생 표시를 분리한다. 모바일에서는 플레이어·스크롤 목록·맨 아래 닫기를 유지한다. 검색은 재생 상태를 바꾸지 않는다.

프런트 81개·Rust 57개 통과(외부 연결 5개 제외), 웹 TypeScript·정적 빌드 통과. 브라우저에서 검색 결과 없음·프로그램명 검색·검색 중 HappyFM 재생 유지/정지(음량 0), 320/390px 가로 넘침 없음, 모바일 접기→데스크톱 항상 노출→모바일 접기 상태 유지, 라이트/다크 캡처 확인. 공개 배포하지 않은 로컬 프리뷰다.

배치 조정: 전체 최대 폭 720px 중앙 정렬, 플레이어와 320px 채널 목록 사이 24px 간격. 로컬 데스크톱 화면·웹 빌드 확인.

양옆 다운로드 영역을 제거하고 플레이어 아래에 공식 다운로드 페이지 링크를 배치했다. 데스크톱 커버 높이는 200px로 줄였으며 원본 비율은 유지한다. TypeScript·웹 빌드, 실제 화면과 320px 가로 넘침 없음 확인.

## UI 보강 — 2026-11-02

프로그램명을 주제목으로, 채널명을 보조 정보로 표시하며 프로그램 정보가 없으면 채널명을 사용한다. 채널 검색창 아래만 내부 스크롤하고 공식 사이트 청취 채널은 별도 구역에서 새 창으로 연다. 외부 링크는 현재 선택·청취를 변경하지 않는다. 재생·연결·오류 상태를 행 오른쪽에 표시하며 음성 막대는 동작 줄이기 설정을 따른다. 표지 영역의 배경·비율 보존을 통일하고 이전/다음 버튼 아래에 이동 대상 채널명을 표시한다.

81개 프런트 테스트, 데스크톱/웹 빌드 및 웹 TypeScript 통과. Rust 57개 통과·외부 검사 5개 제외. 브라우저에서 실제 연결의 재생 막대·정지, 검색 중 재생 유지, 별도 공식 채널 검색, 목록 내부 스크롤, 라이트/다크 및 320px 가로 넘침 없음을 확인했다. 음량 0 재생 이벤트 확인이며 사람의 청취 시험은 아니다. 로컬 프리뷰만 변경했다.

## 디자인 재구성 — 2026-11-02

최신 사용자 요청으로 채널을 2열로 전환하고 검색·이전/다음·음량 슬라이드를 제거했다. 프로그램명 옆에 단일 재생/정지 버튼을 배치하고 플레이어 아래 PC 앱 다운로드 링크를 전체 폭 강조 버튼으로 제공한다. 앱 출력 음량은 100이며 시스템 음량을 사용한다. 초기 무음·단일 재생기는 유지한다.

기존 카드 외곽선을 제거하고 표지·프로그램명 중심으로 정리했다. 프로그램명 아래에 채널명, 그 아래 실제 연결 상태와 공식 링크를 둔다. 긴 제목은 두 줄, 채널 행은 말줄임. 검색 없는 2열 채널 목록은 내부 스크롤하며 공식 사이트 청취 구역은 별도로 유지한다. 안내는 footer 펼침으로 제공한다. 아이콘은 일관된 SVG를 사용한다. PRODUCT.md, DESIGN.md와 .impeccable/design.json에 현재 기준을 기록했다.

프런트 81개·데스크톱/웹 빌드 및 웹 TypeScript 통과. 데스크톱 라이트/다크·모바일과 실제 288px 너비에서 가로 넘침 없음을 확인했다. 공개 배포가 아닌 로컬 프리뷰 변경이다.

후속 배치: 840px 이상·높이 640px 이상에서는 헤더/푸터 사이 작업 영역에 플레이어를 세로 중앙 정렬하고 문서 스크롤 없이 채널 영역만 내부 스크롤한다. 720px 높이에서 플레이어 중심 y=360, 채널 scrollTop 0→427에도 playerTop 163.55px 유지, 페이지 높이=화면 높이를 확인했다. 낮은 화면은 최소 높이로 컨트롤 잘림을 방지한다. 다운로드 위에 메뉴 막대·트레이 접근과 미니 모드 장점을 안내한다. TypeScript·웹 빌드 통과.

간격 후속: 기본 재생 안내·재생 중 문구를 제거해 빈 상태 영역도 숨긴다. 연결 중 안내와 오류는 유지한다. 채널 행은 78→58px, 행 간격은 6→2px로 축소했다. 브라우저에서 안내 숨김·실제 행 58px·내부 스크롤(콘텐츠 666px/영역 471px)을 확인했고 웹 TypeScript·빌드 통과.
