개인정보처리방침

시행일 · 최종 수정일: 2026년 10월 18일

모퉁이 라디오 운영자 Sejong Park는 앱과 소개·다운로드 웹사이트에서 처리하는 정보 및 이용자의 선택 방법을 아래와 같이 안내합니다.

앱은 회원가입 없이 이용할 수 있습니다. 앱 사용 통계는 기본 꺼짐이며 동의한 경우에만 전송합니다. 웹사이트의 방문 통계는 앱 통계와 별도로 수집합니다.

1. 기기에 저장하는 정보

채널 순서·비활성 상태, 음량, 마지막 채널, 화면·시작 설정, 안내 완료 여부, 통계 공유 선택과 무작위 설치 식별자는 기기에 저장합니다. 운영자가 별도의 계정 서버로 이 설정 파일을 수집하지 않습니다. 앱 삭제 후에도 운영체제에 설정 파일이 남을 수 있습니다.

2. 방송 재생과 외부 서비스 연결

웹 라디오도 공식 방송사 서버에 직접 연결하며 이 과정에서 IP 주소 등 통신 정보가 방송사에 전달됩니다. 마지막 채널과 테마는 브라우저에 저장합니다. 웹 청취는 계정 없이 이용하며 새로 열 때 자동 재생하지 않습니다.

방송 재생, 편성표 및 프로그램 이미지 요청은 공식 방송사 서버에 직접 연결됩니다. 업데이트 확인·설치파일 다운로드와 홈페이지 제공에는 GitHub를 사용합니다. 이 과정에서 각 서비스에 IP 주소, 요청 주소 등 통신에 필요한 정보가 전달될 수 있으며 해당 서비스의 처리방침이 적용됩니다.

3. 선택형 앱 사용 통계

앱 개선과 재생 오류 파악을 위해 사용자가 시작 안내 또는 설정에서 통계 공유를 켠 경우에만 다음 정보를 전송합니다.

  • 무작위 설치 식별자, 운영체제 종류, 앱 버전
  • 앱 실행, 재생 성공·실패, 채널 이동 방식, 기능 사용 여부, 청취 시간 요약, 버전 변경

이름·이메일·채널명·프로그램명·스트리밍 주소·오류 원문·오디오·화면 녹화는 앱 통계에 포함하지 않습니다. 설치 식별자로 재방문을 구분하므로 완전 익명인 통계는 아닙니다. IP 기반 위치 추정과 사용자 프로필 생성은 비활성화하지만, 전송 서버는 네트워크 연결상 IP 주소를 볼 수 있습니다.

처리 서비스는 PostHog Cloud(미국 US 리전)입니다. 통계 공유를 켠 동안 이벤트 발생 시 인터넷으로 전송합니다. 공유를 거부해도 라디오 기능은 그대로 이용할 수 있습니다. 설정에서 끄면 이후 전송은 중단되며, 이미 전송된 기록이 자동 삭제되지는 않습니다.

앱 통계의 보관 운영 정책은 90일입니다. 다만 현재 PostHog 프로젝트의 보관·삭제 설정 적용은 확인 중이므로 90일 후 자동 삭제를 보장하지 않습니다. 삭제 요청은 아래 문의처로 접수할 수 있습니다.

4. 웹사이트 방문 통계

통합 사이트에서 PC 앱 다운로드 탭을 열면 Google Analytics 4가 로드됩니다. 이후 사이트 방문·이동과 다운로드 버튼 클릭을 분석하며, 라디오의 선택 채널·프로그램명·청취 시간·오디오는 웹 통계로 보내지 않습니다. 페이지 방문과 이용 환경, 쿠키 기반 식별자 및 다운로드 버튼 클릭(선택한 OS·아키텍처·버전·대상 링크)을 분석해 사이트를 개선합니다. 클릭은 실제 다운로드 완료나 앱 설치를 의미하지 않습니다.

현재 웹 통계는 다운로드 탭을 열 때 로드되며 앱의 통계 동의 설정과 별개입니다. 앱 설치 식별자와 웹 방문자를 연결하지 않습니다. Google Signals와 광고 개인 최적화 신호는 비활성화했습니다.

Google로 요청 주소·IP 등 접속 정보가 전송되고 쿠키가 사용될 수 있으며, 해외에서 처리될 수 있습니다. 웹 통계의 실제 보관 기간은 Google Analytics 속성 설정에 따르며 현재 설정값은 확인 중입니다. 앱 통계의 90일 정책을 웹 통계에 적용한다고 안내하지 않습니다.

브라우저의 추적 방지 기능 또는 Google Analytics 차단 부가기능을 이용할 수 있습니다. 쿠키 삭제만으로 이후 수집이 모두 차단되지는 않습니다. 이 개인정보처리방침 페이지에는 분석 스크립트를 넣지 않았습니다.
